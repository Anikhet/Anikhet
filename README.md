## Side Projects

### AstroAgent &nbsp;·&nbsp; [code](https://github.com/Anikhet/astroagent)

A voice-enabled astronomy assistant. A 5-tool agent talking to the OpenAI Realtime API over WebRTC, paired with a real-time Three.js scene that renders 8 planetary bodies. Cached position lookups stay under a millisecond and tool calls stay under 100ms.

**Built with:** Next.js 15 · FastAPI · Three.js
